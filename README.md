# PR-Screenshots

Nur Ablage für die Screenshots im PR „Google Fonts entfernen, Cormorant Garamond
lokal ausliefern". Dieser Branch wird nicht gemergt und gehört nicht zur
veröffentlichten Seite; er enthält ausschließlich Bilder.

Aufgenommen gegen einen lokalen statischen Server, ganze Seite, Breite 1440,
Sprache Deutsch. `*-vorher.jpg` ist der Stand von `main` (Schriften von Google),
`*-nachher.jpg` der Stand von `fonts-local` (Schriften lokal).

`schrift-detail-*.png` ist ein Ausschnitt der Überschrift „Ein Geschenk, das bleibt."
auf `/corporate/` bei 200 % — vorher und nachher pixelgleich.
